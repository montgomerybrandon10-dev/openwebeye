# OpenWebEye

Open-source facial OSINT platform.

**Live domain:** https://openwebeye.com

## Features

- Face Search (local index)
- 1:1 Comparison
- Face Indexing
- Multi-source search (FaceCheck.id, PimEyes, OSINT)
- Dashboard

## Deploy

Deployed on Vercel. Set `FACECHECK_API_TOKEN` for FaceCheck searches.
